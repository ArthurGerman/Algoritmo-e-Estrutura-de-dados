# Centro de Controle Espacial

## Como rodar
1. `npm install`
2. `npm run build` (gera os .js ao lado dos .ts)
3. Simulação no console: `node Main.js`
4. Interface web: sirva a pasta com um servidor local (módulos ES não funcionam abrindo o
   index.html direto por file://). Ex.: `npx serve .` ou a extensão Live Server do VS Code.
