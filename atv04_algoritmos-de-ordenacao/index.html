    Por que Bubble Sort aqui?

    • O comparador é a.prioridade - b.prioridade, então o algoritmo ordena objetos, não só números.
    • O Bubble Sort é estável: só troca quando a prioridade é estritamente maior. Pacientes com a mesma prioridade continuam na ordem de chegada.
    • Como a fila já está quase ordenada, a otimização que para ao não haver trocas poupa passadas. Um caso urgente que chega no fim, porém, sobe só uma posição por passada.
