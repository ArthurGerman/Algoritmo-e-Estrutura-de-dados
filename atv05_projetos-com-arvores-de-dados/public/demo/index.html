Estruturas de Dados

Bem-vindo! Este mini-site existe para demonstrar o crawler: ele tem páginas ligadas entre si, links repetidos, ciclos e alguns casos especiais.

Árvores

  • Árvore AVL
  • Trie
  • Árvore binária de busca

Algoritmos

  • Ordenação
  • Busca

Casos especiais

  • Área privada (bloqueada pelo robots.txt)
  • Rascunho (marcado com noindex)
  • Link quebrado (HTTP 404)
  • Link com rel="nofollow"
  • Imagem (não é HTML)
  • Site externo (só seguido se a opção permitir)
  • Sobre (com fragmento na URL)
